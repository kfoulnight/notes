

最重要的是先拉取最新的远程代码， 创建自己的分支，将代码提交到自己分支上，再在gitlab上发起合并请求。

commit格式如下：

[feature][M903AT][AERDM-64385]Fix touch screen offset

[what]修复触摸偏移问题

[why]换了新TP触摸与坐标与反馈出来的现象不符合

[how]修改设备树atlas7-M903AT-2B-9-MULTILASER-TOYOTA-SILICON-xinweiTP.dts

[影响等级]C

[测试范围]触摸功能

其中[AERDM-64385] 是jira工单，在jira上创建工单，再将工单id复制粘贴到这里，commit之后jira上会显示你的git信息。
