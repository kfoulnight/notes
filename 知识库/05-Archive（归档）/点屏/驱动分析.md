假设设备树选择：

```text
function = "DES_RXID5_TO_SER";
group = "MAX96755_MFP10";
```

这个 group 定义为：

```c
static int MAX96755_MFP10_pins[] = {10};
```

pinctrl 最终调用：

```c
max96755_pinctrl_set_mux(serdes, function, group);
```

执行过程如下：

### 第一步：找到 function

```c
func = pinmux_generic_get_function(pinctrl->pctl, function);
```

此时找到：

```text
DES_RXID5_TO_SER
```

它的 `func->data` 内容是：

```c
{
	.gpio_out_dis = 0,
	.gpio_rx_en = 1,
	.gpio_tx_en = 0,
	.gpio_rx_id = 5
}
```

### 第二步：找到 group

```c
grp = pinctrl_generic_get_group(pinctrl->pctl, group);
```

此时找到：

```text
MAX96755_MFP10
```

其 pin 编号是：

```c
10
```

### 第三步：配置 GPIO A 寄存器

```c
serdes_set_bits(serdes,
		GPIO_A_REG(10),
		GPIO_OUT_DIS | GPIO_RX_EN | GPIO_TX_EN,
		FIELD_PREP(GPIO_OUT_DIS, 0) |
		FIELD_PREP(GPIO_RX_EN, 1) |
		FIELD_PREP(GPIO_TX_EN, 0));
```

根据宏：

```c
#define GPIO_A_REG(gpio) (0x02be + ((gpio) * 3))
```

所以：

```text
GPIO_A_REG(10) = 0x02be + 10 * 3 = 0x02dc
```

修改：

```text
0x02dc[0] = 0
0x02dc[2] = 1
0x02dc[1] = 0
```

即：

```text
GPIO_OUT_DIS = 0
GPIO_RX_EN   = 1
GPIO_TX_EN   = 0
```

### 第四步：配置 GPIO C 寄存器中的 RX ID

由于：

```c
gpio_rx_en = 1
```

执行：

```c
serdes_set_bits(serdes,
		GPIO_C_REG(10),
		GPIO_RX_ID,
		FIELD_PREP(GPIO_RX_ID, 5));
```

地址为：

```text
GPIO_C_REG(10) = 0x02c0 + 10 * 3 = 0x02de
```

最终相当于：

```text
MAX96755 MFP10 接收 DES GPIO ID 5
```


ARRAY_SIZE:元素个数


GPIO_A_REG/GPIO_B_REG/GPIO_C_REG 3字节GPIO寄存器 

每个GPIO占用3个字节（只有GPIO是3个字节）

每个GPIO从0x0200 + gpio* 3 如:
GPIO0: A=0x0200, B=0x0201, C=0x0202

所以本质是一个GPIO的配置被拆分到3个连续的字节里，每个字节装不同种类的功能。

A：方向/使能/电平状态 
B：电气属性+发送映射
C：接收映射
