# 触摸屏物理原理完整梳理

> [!summary] 核心主线
> 触摸屏的完整链路是：传感层产生电信号变化，触控 IC 扫描并处理信号，通过 I2C / SPI 传给主控，驱动完成协议解析、坐标映射、滤波，最后上报为系统输入事件。

## 一、触摸屏系统的整体结构

触摸屏并不是单一器件，而是一套由传感层、控制 IC、主控处理器和软件驱动共同组成的输入系统。

典型链路如下：

```text
手指 / 触控笔
    ↓
触摸传感层
    ↓
触控控制 IC
    ↓
I2C / SPI / 中断 GPIO
    ↓
主控 SoC / MCU
    ↓
驱动层坐标解析
    ↓
操作系统输入子系统
    ↓
应用层触摸事件
```

其中：

- 传感层负责把触摸动作转换成电信号变化。
- 触控 IC 负责扫描传感层、滤波、计算触点坐标。
- I2C 或 SPI 负责把坐标、状态、手势等数据传给主控。
- 主控驱动负责读取数据、解析协议、上报输入事件。

## 二、触摸屏的主要类型

常见触摸屏主要分为：

- 电阻式触摸屏，Resistive Touch Panel，RTP。
- 电容式触摸屏，Capacitive Touch Panel，CTP。

二者核心区别在于：

| 对比项 | 电阻屏 | 电容屏 |
|---|---|---|
| 检测对象 | 压力导致的导电层接触 | 手指引起的电容变化 |
| 是否需要压力 | 需要 | 通常不需要 |
| 是否支持手套 | 支持普通物体按压 | 普通电容屏不一定支持 |
| 多点触控 | 较难，传统电阻屏多为单点 | 天然适合多点 |
| 透光率 | 相对较低 | 相对较高 |
| 耐用性 | 表面膜层容易磨损 | 玻璃表面更耐用 |
| 成本 | 低 | 相对较高 |
| 典型场景 | 工控、仪表、老式设备 | 手机、平板、车机、消费电子 |

## 三、电阻屏工作原理

### 3.1 基本结构

典型四线电阻屏由两层透明导电膜组成，中间通过微小绝缘点隔开。

```text
上层 PET 膜，内侧涂 ITO
绝缘隔点
下层玻璃或 PET，内侧涂 ITO
```

ITO 是氧化铟锡，是一种透明导电材料。

当手指、笔尖或其他物体按压屏幕时，上下两层 ITO 在触点处接触，形成电气连接。控制器通过给某一方向施加电压，再测量接触点电压，推算触摸坐标。

### 3.2 四线电阻屏坐标测量

四线电阻屏通常有四个引脚：

- X+
- X-
- Y+
- Y-

测量 X 坐标时：

```text
X+ 加 Vref
X- 接 GND
Y+ / Y- 作为电压采样端
```

此时 X 方向形成一个线性电阻分压。触点越靠近 X+，采样电压越高；越靠近 X-，采样电压越低。

测量 Y 坐标时：

```text
Y+ 加 Vref
Y- 接 GND
X+ / X- 作为电压采样端
```

此时 Y 方向形成线性电阻分压。控制器通过 ADC 读取电压值，再换算为坐标。

### 3.3 电阻屏坐标换算

理想情况下：

```text
X = ADC_X / ADC_MAX * Screen_Width
Y = ADC_Y / ADC_MAX * Screen_Height
```

实际系统中还需要校准，因为存在：

- 传感层电阻不均匀。
- 安装偏移。
- 屏幕旋转。
- 机械形变。
- ADC 噪声。

常见校准方式是采集几个已知点，例如四角或五点校准，然后通过线性变换或仿射变换把原始 ADC 坐标映射到屏幕显示坐标。

### 3.4 电阻屏特点

优点：

- 可用手指、指甲、普通笔、戴手套触发。
- 结构简单，成本低。
- 对触摸物体是否导电不敏感。

缺点：

- 需要按压力。
- 表面膜层容易磨损。
- 透光率和触感不如电容屏。
- 多点触控能力弱。
- 响应速度和寿命通常不如电容屏。

## 四、电容屏工作原理

### 4.1 电容的基本概念

电容可以理解为两个导体之间储存电荷的能力。简化公式如下：

```text
C = ε * A / d
```

其中：

- C 是电容值。
- ε 是介质介电常数。
- A 是导体有效面积。
- d 是导体间距。

当手指靠近或触摸屏幕时，人体作为导体会与触摸电极之间形成耦合电容，从而改变原有电场分布。触控 IC 检测这种微小电容变化，并计算触摸位置。

### 4.2 自电容与互电容

电容屏主要有两种检测方式：

- 自电容，Self Capacitance。
- 互电容，Mutual Capacitance。

#### 自电容

自电容检测的是单个电极相对于地的电容变化。

```text
电极 ←→ 手指 / 大地
```

手指靠近电极后，该电极到地的等效电容增大。控制 IC 通过逐个扫描电极，判断哪些区域电容发生变化。

自电容优点：

- 信号强，灵敏度高。
- 适合接近检测、按键、滑条等简单触控。

自电容缺点：

- 多点触控时容易产生鬼点。
- 精确多指识别能力较弱。

#### 互电容

互电容检测的是驱动电极 TX 与感应电极 RX 之间的耦合电容。

```text
TX 电极 ))) 电场 ((( RX 电极
             ↑
           手指影响电场
```

没有触摸时，TX 与 RX 之间存在固定耦合电容。手指靠近交叉区域后，会吸收或改变部分电场，使 TX-RX 之间的互电容发生变化。

控制 IC 扫描 TX/RX 交叉矩阵，就能得到一张二维电容变化图。

互电容优点：

- 支持真实多点触控。
- 可定位多个手指。
- 适合手机、平板、车机等复杂交互。

互电容缺点：

- 控制算法更复杂。
- 对噪声、湿手、水滴、电磁干扰更敏感。
- 对硬件布局和屏幕叠层要求更高。

### 4.3 投射式电容屏结构

现代手机和平板常用投射式电容屏，Projected Capacitive Touch，P-CAP。

典型结构：

```text
盖板玻璃
光学胶 OCA
ITO / 金属网格触控电极
显示面板
背光或 OLED 发光层
```

触控电极通常分为：

- TX，驱动通道。
- RX，接收通道。

TX 与 RX 形成交叉矩阵，每一个交叉点都是一个可检测的触控单元。

### 4.4 电容变化如何被测量

触控 IC 通常不会直接读取一个静态电容值，而是通过充放电、振荡频率、积分电荷或电荷转移等方式把电容变化转换为可测量的数字量。

常见思路包括：

- 给 TX 通道施加激励信号。
- RX 通道接收耦合信号。
- 手指触摸导致接收信号幅度或相位变化。
- 模拟前端放大并滤波。
- ADC 或计数器转换为数字值。
- 数字算法生成触摸强度矩阵。

简化流程：

```text
扫描 TX0 → 读取所有 RX
扫描 TX1 → 读取所有 RX
扫描 TX2 → 读取所有 RX
...
得到完整二维电容矩阵
```

### 4.5 电容屏特点

优点：

- 支持多点触控。
- 灵敏度高，不需要明显压力。
- 透光率高，表面可使用玻璃。
- 寿命长，用户体验好。

缺点：

- 普通非导电物体无法触发。
- 戴厚手套可能无法使用。
- 对水滴、湿手、噪声和接地状态敏感。
- 硬件和算法复杂度较高。

## 五、触控控制 IC 的作用

触控 IC 是触摸屏系统的核心控制器，主要职责包括：

- 扫描触摸传感通道。
- 测量电压、电阻或电容变化。
- 进行噪声滤波。
- 判断是否有触摸。
- 计算触点坐标。
- 识别多点、手势或按键。
- 通过 I2C / SPI / USB / UART 等接口向主控上报数据。

对于电阻屏，触控 IC 通常集成：

- 开关矩阵，用于切换 X/Y 方向激励。
- ADC，用于采样分压值。
- 压力检测逻辑。

对于电容屏，触控 IC 通常集成：

- TX 驱动电路。
- RX 模拟前端。
- 电荷放大器。
- ADC 或计数器。
- DSP / MCU 内核。
- 固件算法。
- 坐标上报协议。

## 六、I2C 通信原理

### 6.1 I2C 基本特征

I2C 是触摸屏中最常见的控制接口，尤其常见于电容触控 IC。

I2C 使用两根信号线：

- SCL，时钟线。
- SDA，数据线。

特点：

- 半双工。
- 多主多从理论可行，实际多为一个主控多个从设备。
- 通过 7-bit 或 10-bit 地址访问从设备。
- 需要上拉电阻。
- 常见速率为 100 kHz、400 kHz、1 MHz。

### 6.2 触控 IC 的 I2C 数据读取方式

触控 IC 通常作为 I2C 从设备，主控作为 I2C 主设备。

典型连接：

```text
主控 SoC / MCU        触控 IC
SCL ---------------> SCL
SDA <--------------> SDA
INT <--------------- INT
RST ---------------> RESET
```

其中：

- INT 是触控中断引脚。
- RST 是复位引脚。

典型流程：

```text
1. 用户触摸屏幕
2. 触控 IC 扫描到触摸
3. 触控 IC 拉低或拉高 INT
4. 主控检测到中断
5. 主控通过 I2C 读取触控数据寄存器
6. 主控解析触点数量、坐标、状态
7. 主控上报输入事件
```

### 6.3 常见 I2C 触控数据格式

不同厂商协议不同，但常见字段类似：

```text
寄存器地址 0x00：设备状态
寄存器地址 0x01：触点数量
寄存器地址 0x02：触点 1 X 高位
寄存器地址 0x03：触点 1 X 低位
寄存器地址 0x04：触点 1 Y 高位
寄存器地址 0x05：触点 1 Y 低位
寄存器地址 0x06：触点 1 ID / 状态
...
```

一个多点触控报文通常包含：

- 触点数量。
- 每个触点的 ID。
- 每个触点的 X 坐标。
- 每个触点的 Y 坐标。
- 触摸状态，例如 down、move、up。
- 可选压力、面积、手势码。

## 七、SPI 通信原理

### 7.1 SPI 基本特征

SPI 是另一种常见外设通信接口，在部分电阻屏控制器或高速触控方案中使用。

SPI 常见信号线：

- SCLK，时钟。
- MOSI，主出从入。
- MISO，主入从出。
- CS / SS，片选。

特点：

- 全双工或半双工。
- 速率通常高于 I2C。
- 不需要设备地址，通过片选区分设备。
- 协议简单，但占用引脚更多。

### 7.2 电阻屏 SPI 控制器示例逻辑

很多电阻屏控制器通过 SPI 接收命令并返回 ADC 值。

典型流程：

```text
1. 主控拉低 CS
2. 主控通过 MOSI 发送测量 X 的命令
3. 控制器切换内部开关并采样 ADC
4. 主控通过 MISO 读取 X 原始值
5. 主控发送测量 Y 的命令
6. 主控读取 Y 原始值
7. 主控拉高 CS
```

常见命令可能包括：

- 读取 X 坐标。
- 读取 Y 坐标。
- 读取 Z1 / Z2 压力相关值。
- 进入低功耗模式。

### 7.3 I2C 与 SPI 对比

| 对比项 | I2C | SPI |
|---|---|---|
| 信号线 | SCL、SDA | SCLK、MOSI、MISO、CS |
| 引脚数量 | 少 | 多 |
| 设备选择 | 地址 | 片选 |
| 速度 | 中等 | 较高 |
| 协议复杂度 | 略高 | 较低 |
| 常见用途 | 电容触控 IC | 电阻屏控制器、高速外设 |
| 中断配合 | 常见 | 也常见 |

## 八、坐标采样逻辑

### 8.1 电阻屏采样逻辑

电阻屏的坐标采样本质是 ADC 分压采样。

基本流程：

```text
检测是否按下
    ↓
采样 X 原始值
    ↓
采样 Y 原始值
    ↓
可选采样压力 Z
    ↓
多次采样求平均或取中值
    ↓
坐标校准
    ↓
上报坐标
```

常见抗噪处理：

- 连续采样多次。
- 去掉最大值和最小值。
- 求平均值。
- 坐标变化小于阈值时保持稳定。
- 抬起时上报 release 事件。

电阻屏压力判断常通过 Z1/Z2 或接触电阻估算。压力越大，上下导电层接触越充分，接触电阻越小。

### 8.2 电容屏采样逻辑

电容屏采样本质是二维电容矩阵扫描与图像处理。

简化流程：

```text
建立基线电容矩阵
    ↓
周期扫描 TX/RX 通道
    ↓
得到当前电容矩阵
    ↓
当前值与基线值相减
    ↓
得到触摸强度变化矩阵
    ↓
寻找峰值区域
    ↓
计算触点中心
    ↓
分配触点 ID
    ↓
滤波与轨迹跟踪
    ↓
上报多点坐标
```

### 8.3 基线与差分

电容屏不会只看单次绝对值，而是维护一个基线：

```text
Delta = Current - Baseline
```

或根据芯片定义使用：

```text
Delta = Baseline - Current
```

基线会随着环境缓慢更新，用于适应：

- 温度变化。
- 湿度变化。
- 屏幕老化。
- 电源噪声变化。
- 结构件接地状态变化。

但当检测到真实触摸时，基线更新通常会暂停或减慢，避免把手指长期按压误学成背景。

### 8.4 峰值检测与坐标插值

触摸点通常不会只影响一个电极交叉点，而是影响一片区域。

例如得到一个触摸强度矩阵：

```text
0   1   3   1   0
1   5  12   6   1
2  10  25  11   2
1   4  10   5   1
0   1   2   1   0
```

算法会找到峰值附近区域，并计算重心：

```text
X = Σ(xi * weight_i) / Σ(weight_i)
Y = Σ(yi * weight_i) / Σ(weight_i)
```

这样可以获得高于电极物理间距的坐标分辨率。

### 8.5 多点触控 ID 跟踪

电容屏支持多个触点。控制 IC 或驱动需要在连续帧之间判断哪个点是同一个手指。

典型依据：

- 上一帧位置。
- 当前帧位置。
- 移动距离。
- 触点面积。
- 触点强度。
- 触点生命周期。

系统通常会给每个触点分配一个 tracking ID。只要手指没有抬起，同一个手指会持续使用同一个 ID。

### 8.6 坐标映射

触控 IC 输出的坐标通常是触控传感器坐标，不一定等于显示坐标。

驱动或系统需要处理：

- 分辨率缩放。
- X/Y 轴交换。
- X 轴镜像。
- Y 轴镜像。
- 屏幕旋转 90/180/270 度。
- 触摸有效区域裁剪。

示例：

```text
Display_X = Raw_X * Display_Width / Touch_Max_X
Display_Y = Raw_Y * Display_Height / Touch_Max_Y
```

如果屏幕旋转，还需要对应变换：

```text
旋转 90 度：
Display_X = Raw_Y
Display_Y = Touch_Max_X - Raw_X
```

## 九、触控事件上报逻辑

### 9.1 单点触控事件

单点触控通常包括：

```text
按下 down
移动 move
抬起 up
```

驱动读取坐标后，会向系统输入子系统上报：

- 是否按下。
- X 坐标。
- Y 坐标。
- 可选压力。

### 9.2 多点触控事件

多点触控需要描述多个手指。

每个触点通常包含：

- slot。
- tracking ID。
- X 坐标。
- Y 坐标。
- pressure。
- touch major / minor。
- event flag。

典型状态变化：

```text
手指 A 按下 → 分配 ID 1
手指 B 按下 → 分配 ID 2
手指 A 移动 → ID 1 坐标更新
手指 B 抬起 → ID 2 释放
手指 A 继续移动 → ID 1 保持
手指 A 抬起 → ID 1 释放
```

## 十、中断、轮询与低功耗

触摸屏数据读取通常有两种方式：

- 中断方式。
- 轮询方式。

### 10.1 中断方式

触控 IC 检测到新数据后，通过 INT 引脚通知主控。

优点：

- 实时性好。
- 低功耗。
- 主控不需要频繁查询。

常见流程：

```text
触摸发生
    ↓
触控 IC 拉动 INT
    ↓
主控中断服务程序触发
    ↓
调度驱动读取 I2C / SPI 数据
    ↓
清除中断状态
```

### 10.2 轮询方式

主控定时读取触控 IC 状态。

优点：

- 实现简单。
- 不依赖中断 GPIO。

缺点：

- 功耗更高。
- 延迟取决于轮询周期。
- 可能读取无效数据。

## 十一、噪声与抗干扰

触摸屏容易受到以下因素影响：

- LCD / OLED 显示噪声。
- 充电器噪声。
- 电源纹波。
- 射频干扰。
- 水滴和湿手。
- 结构件接地不良。
- 玻璃厚度变化。
- 温湿度变化。

常见处理方法：

- 硬件屏蔽和良好接地。
- 电源滤波。
- 差分测量。
- 多频扫描。
- 跳频避开噪声频段。
- 数字滤波。
- 阈值自适应。
- 防水算法。
- 手掌误触抑制。

## 十二、电容屏与电阻屏在软件驱动上的差异

| 软件处理项 | 电阻屏 | 电容屏 |
|---|---|---|
| 原始数据 | ADC X/Y/Z | 多通道电容矩阵或 IC 坐标 |
| 校准需求 | 通常需要 | 通常由 IC 或固件处理 |
| 多点支持 | 传统方案较弱 | 常见支持 |
| 滤波重点 | ADC 抖动、压力稳定 | 噪声、误触、轨迹平滑 |
| 上报方式 | 单点坐标较多 | 多点 slot / tracking ID |
| 控制接口 | SPI、ADC、GPIO | I2C、SPI、USB |

## 十三、常见调试思路

### 13.1 无触摸响应

排查方向：

- 供电是否正常。
- 复位脚电平是否正确。
- I2C / SPI 是否能通信。
- 设备地址是否正确。
- INT 是否有变化。
- 驱动是否匹配芯片型号。
- 固件是否加载成功。
- 屏幕排线是否接触良好。

### 13.2 坐标反向或旋转

排查方向：

- X/Y 是否交换。
- X 轴是否镜像。
- Y 轴是否镜像。
- 显示屏旋转配置是否一致。
- 设备树或驱动参数是否配置正确。

### 13.3 触摸漂移或抖动

排查方向：

- 电源噪声。
- 接地不良。
- 采样滤波参数。
- 基线更新异常。
- 屏幕受潮。
- 充电器干扰。
- 结构压迫导致传感层异常。

### 13.4 多点异常

排查方向：

- 触控 IC 是否支持对应点数。
- 协议解析是否正确。
- tracking ID 是否正确维护。
- 坐标包长度是否读取完整。
- 中断清除时序是否正确。

## 十四、总结

电阻屏和电容屏的根本差异在于检测物理量不同。电阻屏通过压力让两层导电膜接触，再用分压和 ADC 计算坐标；电容屏通过检测手指引起的电容变化，扫描电极矩阵并计算触摸中心。电阻屏结构简单、成本低、支持任意物体按压，但体验和多点能力有限；电容屏体验好、支持多点触控，是现代消费电子主流方案，但对硬件设计、噪声控制和算法要求更高。

从系统角度看，触摸屏的完整工作链路是：传感层产生电信号变化，触控 IC 扫描并处理信号，通过 I2C 或 SPI 把坐标数据传给主控，驱动再完成协议解析、坐标映射、滤波和输入事件上报。理解这条链路，有助于分析触摸失效、坐标反向、抖动、误触、多点异常等实际问题。
